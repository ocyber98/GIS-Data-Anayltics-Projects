# Green Roof Suitability Analysis Using GIS

## Overview

GIS-based suitability analysis identifying potential locations for green roof installation at UMBC using LiDAR-derived elevation data and spatial analysis.

## Objective

The goal of this project was to identify areas of UMBC where green roof installation may be suitable based on roof flatness and elevation-related criteria.

## Data

- LiDAR-derived DEM/DSM
- UMBC building footprints
- Elevation data
- Campus GIS layers

## Methods

- DEM/DSM processing
- Raster analysis
- Slope/flatness analysis
- Reclassification
- Suitability analysis
- Spatial overlay

## Tools

ArcGIS Pro, Spatial Analyst, LiDAR

## Results

The analysis identified buildings and areas that met the selected suitability criteria.
